# CSS Implementation Batch 2 - 2026-11-12

This delivery implements 10 targeted CSS features across the Solid Native / Zig rendering engine covering 2024 baseline foundations and 2025 additions.

No tests, builds, typechecks, browser comparisons or test authoring ran. The user explicitly paused them. Status is implementation-only and unverified.

## Native & Bridge Architecture Changes

- **Logical Properties (#298)**: Added `overflowBlock` and `overflowInline` to `Style` in `modules/ui_core/style.zig` and mapped them in `physicalStyle` in `packages/solid-zig/src/native.js` based on `writingMode` (block maps to Y in `horizontal-tb` and X in vertical modes; inline maps to X in `horizontal-tb` and Y in vertical modes). Updated `effectiveOverflowX()` and `effectiveOverflowY()` in `modules/ui_core/scene.zig` to resolve logical overflow properties natively.
- **Font Feature Settings (#296)**: Added `fontFeatureSettings` to `Style` and `Typography` (`modules/ui_core/text.zig`), mapped through `NativeStyle` in `src/text_backend.zig` and `TextStyle` in `src/text_backend.c`. Added `@font-face` descriptor registry in `packages/solid-zig/src/native.js` allowing default font feature settings to inherit from registered font families.
- **Details Content (#295)**: Added disclosure box partitioning in `packages/solid-zig/src/native.js` for `<details>`. Children other than `<summary>` are wrapped in a dedicated `details-content` pseudo-element container box whose display toggles with `open` and accepts `detailsContent` styling. Made `<summary>` clickable to toggle disclosure state.
- **Content Visibility (#294)**: Added `contentVisibility`, `containIntrinsicWidth`, and `containIntrinsicHeight` to `Style`. Implemented viewport intersection test `skipsContents(viewport, bounds)` in `modules/ui_core/scene.zig`. Stacking context collection (`appendContext`) skips traversing and painting descendants when an element's contents are skipped under `content-visibility: auto` (off-screen) or `hidden`.
- **Attr() Expressions (#292)**: Implemented declaration-value `attr()` substitution in `packages/solid-zig/src/native.js` (`resolveAttr`). Supports reading element attributes/props in kebab-case and camelCase, optional unit/type appending (e.g. `px`), and fallback expressions (`attr(data-size px, 20px)`).
- **Active View Transition (#291)**: Added `startViewTransition` API and active transition state tracking with transition type sets in `packages/solid-zig/src/native.js`. Added `activeViewTransition` flag to `Style` and applied `activeViewTransition` style overrides to root elements while transitions are active.
- **Absolute Positioning Alignment (#290)**: Implemented `align-self`, `justify-self`, and `place-self` alignment for out-of-flow (absolutely positioned) boxes in `modules/ui_core/scene.zig`. Supports all alignment values (`start`, `self-start`, `flex-start`, `center`, `end`, `self-end`, `flex-end`, `stretch`, `normal`, `auto`, `left`, `right`) within inset-modified containing blocks, expanding dimensions automatically when `stretch` is combined with auto sizes.
- **Zoom (#288)**: Added `zoom` and `zoomCss` to `Style`. Implemented CSS zoom inheritance in `inheritComputedStyle` in `modules/ui_core/scene.zig` and in `packages/solid-zig/src/native.js`. Scaled `fontSize`, `padding`, `border`, `margin`, and box sizing (`borderSize`) by the accumulated zoom factor.
- **Z-Index (#287)**: Added integer parsing (including negative integers, positive integers, and `auto`) for `zIndex` in `packages/solid-zig/src/native.js`. Updated `appendContext` in `modules/ui_core/scene.zig` to sort stacking context participants and paint negative z-index descendants (`zIndex < 0`) before the stacking context root element and non-negative descendants after it, aligning with CSS 2.1 stacking context painting and hit-testing rules.
- **Writing Mode (#286)**: Supported `horizontal-tb`, `vertical-lr`, and `vertical-rl` values for `writingMode`. Handled CSS inheritance down the tree in `inheritComputedStyle` and `packages/solid-zig/src/native.js`. Updated `computeBlockLayout` in `modules/ui_core/layout_block.zig` to translate block progression and coordinates for vertical-lr and vertical-rl modes.
