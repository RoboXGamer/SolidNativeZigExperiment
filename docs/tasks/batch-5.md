# CSS Typography & Text Subsystem Batch 5 — 2026-11-12

Implementation delivery for 10 GitHub issues covering the CSS 2024 Baseline typography, text wrapping, text decoration, text stroke/fill, text shadows, and text overflow features.

Testing PAUSED: No builds, tests, typechecks, browser comparisons, or test authoring ran for this batch per user instruction. All statuses are implementation-only and unverified.

## Native Architectural Changes

- **Text Indent (`text-indent`, #251):** First-line indentation is integrated into both shaped line generation (`modules/ui_core/text.zig`) and the block inline formatting context (`modules/ui_core/layout_block.zig`). First in-flow inline lines in block containers offset their starting cursor by `text-indent` while subsequent wrapped lines start at line margin 0. Lengths and percentages (resolved against container inline size) are supported.
- **Text Orientation (`text-orientation`, #252):** Added `mixed`, `upright`, and `sideways` support across `Style`, `Typography`, Uniscribe font creation (`src/text_backend.c`), cache key generation (`src/text_backend.zig`), and inheritance (`modules/ui_core/scene.zig`). Vertical modes (`vertical-rl`, `vertical-lr`) configure font escapement / orientation (2700 for 90° clockwise sideways orientation) while upright keeps glyphs stacked vertically.
- **Text Overflow (`text-overflow`, #253):** Expanded to support both single-value and two-value CSS syntax (`clip`, `ellipsis`, `clip ellipsis`, `ellipsis clip`). Both start-edge (`ellipsizeStart`) and end-edge (`ellipsize`) truncations are computed respecting writing direction (`ltr` vs `rtl`). Clipping containers project their overflow presentation onto descendant text runs.
- **Text Shadows (`text-shadow`, #254):** Added `textShadows` CSS parser in `modules/ui_core/paint.zig` supporting comma-separated shadow layers with X/Y offsets, optional blur radius, and color tokens resolving `currentColor`. Multi-pass shadow rasterization in `src/windows.zig` draws shadows prior to text glyphs with blur spread.
- **Text Stroke and Fill (`text-stroke-fill`, #255):** Implemented `-webkit-text-stroke` / `textStroke` shorthand and longhands `-webkit-text-stroke-width`, `-webkit-text-stroke-color`, and `-webkit-text-fill-color`. Supported across style resolution, `currentColor` resolution, multi-directional radial dilated outline stroke rendering in `src/windows.zig`, and fill color overrides.
- **Text Transform (`text-transform`, #256):** Extended casing engine to support `uppercase_eszett` (German 'ß' -> 'SS'), `turkic_is` (Turkish/Azeri dotted/dotless I casing under language `tr`/`az`), `lowercase_sigma` (Greek capital Sigma 'Σ' to word-final 'ς' vs medial 'σ'), `capitalize`, `uppercase`, and `lowercase` in both native Windows Uniscribe NLS and headless fallback `applyTextTransform`.
- **Text Underline Offset & Position (`text-underline-offset` #257, `text-underline-position` #258):** Implemented `text-underline-offset` (`auto`, length, percentage of computed font-size) and `text-underline-position` (`auto`, `from-font`, `under`, `left`, `right`). Underline geometry calculates baseline offset, descent clearance (`under`), and vertical text side selection (`left`/`right`) with thickness and color in `src/windows.zig`.
- **Text Wrap & Text Wrap Balance (`text-wrap` #259, `text-wrap: balance` #260):** Implemented `text-wrap` shorthand, `text-wrap-mode` (`wrap`, `nowrap`), and `text-wrap-style` (`auto`, `balance`, `stable`, `pretty`). `nowrap` mode suppresses line breaks during shaping. `text-wrap-style: balance` executes a binary search line-balancing algorithm for paragraphs (2–10 lines) finding the minimal line width that produces equalized line lengths without typographic orphans.
