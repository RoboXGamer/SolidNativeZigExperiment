# Static source-review coverage checklist

Audited commit: `8873c31`. Generated by `tools/audit-report.mjs`. These are planning judgments, not executed tests. 0 = missing, 0.5 = partial, 1 = narrowly present. A 1 does not certify surrounding CSS interactions. Subsystem percentages are not added or averaged into a browser conformance score. Each subsystem has ten explicitly named obligations.
