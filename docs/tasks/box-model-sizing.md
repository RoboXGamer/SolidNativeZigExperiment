- [x] **BM-03 / BOX-R03: Constraints.** Share min/max resolution across block/flex/current grid. An explicit minimum zero must disable the automatic content minimum where applicable. - [x] **BM-04 / BOX-R04: One box contract.** Define precisely what layout bounds represent. Implement consistent content, padding, border and margin rectangles and sizes.
